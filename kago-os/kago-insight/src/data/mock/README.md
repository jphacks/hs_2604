# モックデータ

DBが未接続の間、画面を作るための仮データです。

- 値は `docs/specs/common-spec.md` の「11. 架空例による机上確認」に準拠しています。
  11.3・11.4 の期待値と画面の表示が一致するはずなので、INS-03 の完了条件
  「手計算できる固定データと画面の件数・率が一致する」の検証にそのまま使えます。
- 列名も common-spec.md 5章・5.1 に合わせています。
  `sponsored` は `ad_placement_id`、`store_promo` は `promotion_version_id` を持ち、
  `organic` は両方 null です。
- DB-09 のビュー定義（未確定）が決まったら、この形を合わせ直します。
