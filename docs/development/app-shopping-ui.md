# DEMO-10：Appの買い物UI

対象：DEMO-10（#120）。今回は買い物ホームのみ。既存の来店・認証・商品検索・商品追加・かご保存・推薦・クーポン処理を維持する。

## 今回の画面
- ブランドロゴと実際の点数を表示するカートボタン
- カメラ読み取り、検索、果物・惣菜・野菜・パンの入口
- おすすめ商品へのバナー、既存の推薦・クーポンの表示
- 商品一覧、バーコードの手入力、読み取り失敗の案内
- りれき・ホーム・マイページの下部ナビ

カテゴリは表示中の商品を分類するUI。検索は既存のサーバー検索を使う。検索を送信するとカテゴリの絞込みを解除する。50件を超える場合は既存の「さらに表示」で続きも読み込める。店舗の取扱い・価格・権限の仕組みは変えない。

## 後続で必要なUI
| UI | 必要な表示・操作 | 今回 |
|---|---|---|
| カートを押した後 | 商品画像、数量変更、削除、小計・割引・合計、購入への入口、空・通信失敗・取扱停止 | 既存画面を維持。見た目の作り込みは後続 |
| クーポン（DEMO-06 #117） | 商品画像、値引き率、通常／割引後価格、理由、期限、受取・見送り、受取済み、控えめな出現動作 | 後続。既存ロジック・表示は維持 |
| 商品詳細・検索結果 | 写真、商品名、店舗価格、数量、追加成功・該当なし | 一覧と検索を維持。詳細の作り込みは後続 |
| カメラ読み取り中 | 読み取り枠、停止、成功、権限拒否、読取失敗、手入力 | 既存機能を維持。入口の見た目のみ変更 |
| 購入確認・完了 | 明細・割引・合計、購入確定、処理中、完了・失敗 | APP-09（#25）との統合時に確認 |
| 購入履歴 | 一覧、日時・店舗・合計、明細、空・読込失敗 | 既存マイページの履歴へリンク |
| マイページ | 利用者情報、パーソナライズ設定、ログアウト、保存状態 | 既存画面へリンク |
| 音声検索 | 開始・停止・聞取中・許可拒否・非対応 | 今回は追加しない。機能方針の決定後 |

## 素材
- ロゴ・商品画像はリポジトリの既存素材。
- `public/images/shopping/fresh-family.png` は内蔵imagegenで生成したオリジナル画像。
- 生成指示：日本の親子が明るいキッチンでサラダを作る横長写真。人物は右、左は淡い白とミントの余白。自然光、文字・ロゴ・UIなし。
- 参考画像のスマートフォン時刻・電波・電池表示は描かない。端末自身の表示に任せる。
